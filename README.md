# Potepan Share 宿泊予約アプリ
Railsで作成した宿泊予約アプリです。
ユーザー登録・認証、宿泊施設の登録・検索、宿泊予約までの一連の機能を実装しています。

![宿泊予約アプリのER図](docs/images/er-diagram.png)

## 使用技術
- Ruby on Rails 7.2.2.1
- Devise
- SQLite3
- Active Storage
- Tailwind CSS
- Stimulus
- Turbo

### ユーザー機能
- ユーザー登録・ログイン・ログアウト
- アカウント情報の編集
- プロフィールの編集
- アイコン画像の登録
- バリデーションエラーの項目別表示

### 宿泊施設機能
- 宿泊施設の一覧・詳細表示
- 宿泊施設の新規登録・編集・削除
- 自分が登録した宿泊施設の一覧表示
- エリア検索
- 施設名・施設詳細のキーワード検索
- 施設画像の登録

### 予約機能
- 宿泊施設の予約
- 予約内容の確認
- 予約済み一覧の表示
- 予約の編集・削除
- チェックイン日、チェックアウト日、人数のバリデーション
- 宿泊日数・人数を反映した合計料金の計算

## セットアップ
developブランチをgit clone後に以下を実行してください。

```bash
bundle install
bin/rails db:prepare
bin/rails db:seed
bin/dev

シーダーによって、以下のテストデータが作成されます。
- テストユーザー：1人
- テスト施設：10施設
- テスト予約：3件

テストユーザーのログイン情報：
メールアドレス：test@example.com
パスワード：password
```

ブラウザで`http://localhost:3000`にアクセスしてください。

## 動作確認項目

- ユーザー登録・ログイン・ログアウトができる
- アカウント情報とプロフィールを編集できる
- 宿泊施設を新規登録・編集・削除できる
- エリア・キーワードで宿泊施設を検索できる
- 予約内容を確認して予約できる
- 予約を編集・削除できる
- 必須項目や日付条件に対するエラーメッセージが表示される
- 宿泊日数・人数を反映した合計料金が表示される
