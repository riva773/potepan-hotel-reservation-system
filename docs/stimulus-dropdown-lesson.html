アイコン・ユーザー名・矢印のどこをクリックしても、隠れているメニューを表示し、もう一度クリックすると非表示に戻す仕組みを理解する。

今日のゴール：コードを暗記せず、処理の流れを説明できる

1. まず概要

今回の機能は「メニューを新しく作る」機能ではありません。HTMLにすでにあるメニューの、CSSクラスを切り替える機能です。

プロフィールをクリック clickを受け取る ulを見つける hiddenを切り替える 表示 / 非表示

HTML

プロフィールのbuttonと、メニューのulを用意する。

CSS

hiddenが付いている要素を非表示にする。

JavaScript

クリックされたら、hiddenを付けたり外したりする。

Stimulus

HTMLとJavaScriptを、Controller・Action・Targetで結び付ける。

2. Stimulusを使わない場合から考える

Stimulusを理解するために、まず普通のJavaScriptで考えます。

const button = document.querySelector("button")
const menu = document.querySelector("ul")

button.addEventListener("click", () => {
  menu.classList.toggle("hidden")
})
document.querySelector
HTMLから要素を探す
addEventListener("click", ...)
クリックを監視する
classList
要素のclassを扱う
toggle("hidden")
hiddenを付け外しする

StimulusはJavaScriptを別のものにするのではなく、この「要素を探す」「イベントを受け取る」という関係を、HTMLの属性で整理する仕組みです。

3. Stimulusの3つの部品

Controller動作の部品

JavaScriptファイルです。今回ならdropdown_controller.jsがメニューの動作を担当します。

Actionイベントとの接続

「クリックされたら、このControllerのこのメソッドを呼ぶ」という指定です。

Target操作対象

Controllerが操作するHTML要素に名前を付けます。今回はメニューのulです。

data-*HTML上の目印

StimulusはHTMLのdata-*属性を読み、JavaScriptとHTMLを結び付けます。

<div data-controller="dropdown">
  <button data-action="click->dropdown#toggle">
    画像・名前・矢印
  </button>

  <ul data-dropdown-target="menu" class="hidden">
    メニュー項目
  </ul>
</div>
data-controller="dropdown"
dropdown Controllerを使う
click->dropdown#toggle
click時にtoggleを呼ぶ
data-dropdown-target="menu"
ulをmenuという名前で登録

4. 今のアプリのコードに対応させる

現在のアプリでは、Stimulusの読み込み準備はすでにあります。

  • app/javascript/application.jsがControllerを読み込む
  • app/javascript/controllers/index.jsがControllerを自動読み込みする
  • dropdown_controller.jsがdropdownの動作を担当する
  • ログイン時だけ_login_header.html.erbが表示される
import { Controller } from "@hotwired/stimulus"

export default class extends Controller {
  static targets = ["menu"]

  toggle() {
    this.menuTarget.classList.toggle("hidden")
  }
}

このコードを処理の順番で読む

  1. StimulusのController機能を読み込む。
  2. dropdownというControllerを作る。
  3. menuというTargetを登録する。
  4. クリックでtoggle()を呼ぶ。
  5. this.menuTarget、つまりulを操作する。
  6. hiddenを付け外しする。

static targets = ["menu"]は、Stimulusに「このControllerはmenuという操作対象を使います」と登録する設定です。staticの細かなJavaScript仕様を、今すぐ暗記する必要はありません。

演習4：コードの間違いを探す

<div class="data-controller=dropdown">
  <button>プロフィール</button>
  <ul data-dropdown-target="menu" class="hidden">...</ul>
</div>

このコードの問題点を2つ考えてから、答えを開いてください。

① data-controllerがclass属性の中に入っている。② buttonにクリック時のActionがない。なお、TargetのulがControllerの範囲内にある点は正しいです。

演習5：実装前の説明練習

次の3つを自分の言葉で説明してみてください。

  1. data-controller="dropdown"
  2. data-action="click->dropdown#toggle"
  3. this.menuTarget.classList.toggle("hidden")
①この範囲でdropdown Controllerを使う。②クリック時にdropdown Controllerのtoggleメソッドを呼ぶ。③操作対象のメニューのhiddenクラスを付け外しする。

7. 実装するときの確認チェックリスト

  • Controllerファイル名がdropdown_controller.jsになっている
  • HTMLにdata-controller="dropdown"がある
  • クリック対象にdata-action="click->dropdown#toggle"がある
  • メニューのulにdata-dropdown-target="menu"がある
  • TargetのulがControllerの範囲内にある
  • メニューの初期classにhiddenがある
  • ログイン状態で_login_header.html.erbが表示されている
  • 1回目で表示、2回目で非表示になる

8. 用語メモ

DOM

イベント

classList
HTML要素に付いたclassをJavaScriptから扱う窓口
toggle
あれば外し、なければ付ける切り替え
Controller
Stimulusで動作を担当するJavaScriptの部品
Target
Controllerが操作するHTML要素
Action
イベントとメソッドを結び付ける指定
